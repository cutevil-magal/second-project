# Надо сделать идеально

Современная одностраничная концепция, визуализирующая философский взгляд на перфекционизм в работе и творчестве. Минималистичный дизайн с видеофоном и интерактивным элементом, раскрывающим глубинный смысл проекта при взаимодействии.

## 🎯 О проекте

Я создала интерактивную веб-страницу, которая через минималистичный интерфейс передает важную идею о принятии несовершенства в процессе работы. Проект сочетает в себе эстетику видеофона с точным типографическим решением и продуманной микроанимацией.

### ✨ Ключевые особенности

- **Фоновое видео** с автоматическим воспроизведением и интеллектуальным масштабированием
- **Интерактивный заголовок** с появляющимся тултипом при наведении
- **Абсолютное позиционирование** для точного контроля над элементами
- **CSS-анимации** без использования JavaScript
- **Адаптивная верстка** с учетом различных размеров экрана

### 🛠 Технологический стек

**Frontend:**
- HTML5 (семантическая разметка)
- CSS3 (Flexbox, абсолютное позиционирование, псевдоэлементы)
- Видеофон с оптимизацией

**Особенности реализации:**
- Псевдоэлементы `::before` и `::after` для декоративных элементов
- Свойство `object-fit: cover` для адаптации видео
- Спецсимвол `\A` с `white-space: pre` для переносов в контенте
- Наследование высоты через `height: inherit`

## 🎨 Особенности реализации

### Семантическая минимализм
```html
<body>
  <video class="video" autoplay muted loop poster="videos/poster.png">
    <source src="videos/background.mp4" type="video/mp4">
  </video>
  <h1 class="page__heading">Надо сделать идеально<span class="star">*</span></h1>
</body>
```

### Псевдоэлементы для тултипа
```css
.page__heading:hover::before {
  content: 'На самом деле нет.\AВажнее &mdash; научиться ошибаться.';
  white-space: pre;
  position: absolute;
  top: 20px;
  right: 20px;
}
```

### Адаптивное видео
```css
.video {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
  position: absolute;
  top: 0;
  left: 0;
}
```

### Наследование высоты
```css
html {
  height: 100%;
}

body {
  height: inherit;
  position: relative;
  min-width: 800px;
}
```
